# Leo Avelino Blog

Este é meu blog pessoal onde compartilho conhecimentos, experiências e contribuições para a comunidade de desenvolvimento.

## 🎯 Sobre

Este blog foi criado com o objetivo de compartilhar conhecimento sobre desenvolvimento de software, incluindo:
- Bibliotecas e ferramentas que desenvolvi ou contribuí
- Hard skills: técnicas e práticas de programação
- Soft skills: desenvolvimento pessoal e profissional
- Experiências e aprendizados da carreira

## 🚀 Tecnologias

- Next.js
- React
- TypeScript
- Tailwind CSS
- MDX para conteúdo

## 🛠️ Como executar localmente

### Pré-requisitos

- Node.js (versão 18 ou superior)
- npm ou yarn
- Git

### Passos para execução

1. Clone o repositório
```bash
git clone https://github.com/leoavelino/leoavelino-blog.git
cd leoavelino-blog
```

2. Instale as dependências
```bash
npm install
# ou
yarn install
```

3. Execute o projeto em modo de desenvolvimento
```bash
npm run dev
# ou
yarn dev
```

4. Acesse o projeto em `http://localhost:3000`

### Scripts disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a build de produção
- `npm run start` - Inicia o servidor de produção
- `npm run prettier:check` - Verifica a formatação dos arquivos
- `npm run prettier:write` - Formata automaticamente os arquivos
- `npm run magic:components` - Executa o script de exportação de componentes
